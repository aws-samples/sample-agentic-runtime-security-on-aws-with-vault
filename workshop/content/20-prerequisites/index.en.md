Before deploying any infrastructure, set up your environment using the workshop's automation scripts. Work through each sub-module in order:

1. **[Clone the Repository](21-aws-account/)** — Fork, clone, and verify your AWS account access
2. **[Obtain IVIA Licenses](22-ivia-licensing/)** — Obtain the ICR entitlement key and IVIA trial certificate before deploying
3. **[Run Pre-flight Checks](23-pre-flight-checks/)** — Install CLI tools, verify Bedrock model access, quotas, and IAM permissions
